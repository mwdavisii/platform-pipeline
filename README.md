# platform-pipeline

A personal proof of concept of a "golden road" release pipeline for containerized apps: a builder that generates the Dockerfile, deploy manifests, and an authorization guard from a small spec; a drift check that blocks hand-edits to generated files; and reusable GitHub Actions workflows that build, probe, sign, and attest a release, with a separate approval step (Gate 2) before a production release.

This repository is public and exists only as a personal proof of concept.

- Setup and proof run: [docs/setup/personal-poc.md](docs/setup/personal-poc.md)
- Who does what, with a procedure for each role (developers, security, portal admins, Secret Server, identity, data, platform, deploy reviewers): [docs/roles/README.md](docs/roles/README.md)
- What is enforced, where, and what a deploy owner must verify: [docs/enforcement.md](docs/enforcement.md)
- Sample app generated by the builder: [bootstrap/hello-app](bootstrap/hello-app)
