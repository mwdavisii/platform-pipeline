# Golden road agent template

An agent on the golden road is a model with instructions, skills, tools and data, and no code of its own. This repository is its
whole definition: `agent.yaml`. The platform's agent runtime (a signed image) runs it; everything else here is generated by the
builder, and the golden-road checks refuse any other file.

1. Create your repository from this template ("Use this template"), named `agent-<name>` in lower-case letters, digits and `-`.
2. Ask the platform team to add it to the portal's read App and agent App, then wait for the collector's next pass.
3. In the portal, open **Build an agent** and press **Define the agent**: the portal opens a pull request that changes
   `agent.yaml`. Review it and merge it.
4. Register the app in the portal, and pick its skills, MCP servers and data on its page, per environment, as for any app.
5. Release and promote it as for any app. The agent answers at its URL: a chat page for people, and `POST /chat` for other systems
   (`{"messages": [{"role": "user", "content": "..."}]}`).

Don't add files: an agent repo holds `agent.yaml`, this README, the golden-road workflows under `.github/`, and what the builder
generates. Its `app_name` stays `golden-road-agent-template` in every repository made from this one; the image is named after the
repository.
